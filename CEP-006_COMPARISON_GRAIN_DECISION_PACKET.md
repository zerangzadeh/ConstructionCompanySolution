# CEP-006 comparison-grain decision packet

**Date:** 2026-10-15. **State:** decision preparation only; CEP-006 remains EXECUTION PARTIAL. **Repository:** local `main`, HEAD `533fbd52e38dd448973ba4cc618e5faa44b01fec`. No product, model, schema, migration or test mutation is authorized by this packet.

## A. Executive blocker

[PD-033](docs/architecture/BONIRA_PD_033_RECONCILIATION_CURRENT_STATE.md) approves the latest eligible successful complete native run **within the same pair and native comparison grain**. The 13 [published pair specifications](apps/reporting/reconciliation_catalog.py) declare 41 dimensions. The [adapters](apps/reporting/reconciliation.py) aggregate at tenant/project/cutoff level; they do not group by those declared tuples. In particular, `subledger_gl`, `treasury_bank`, and `treasury_gl` sum every retained native run through `created_at <= cutoff`, so repeat runs can be counted twice. The first and third of those pairs lack declared dimensions on their native run records. No native service designates `created_at`, UUID or insertion order as the authoritative order between repeated runs at one business as-of date. Under PD-033's explicit no-guess rule, CEP-006 cannot resume product mutation.

**Classification rule:** `EXACT` means both sides have the stated persisted relationship; `DERIVABLE-WITH-CANONICAL-EVIDENCE` (D) means existing code fixes the derivation; `MISSING` means at least one side lacks usable persisted representation; `AMBIGUOUS` means plausible alternatives lack an authoritative choice. A dimension present on only one side is not called exact. A fixed adapter literal, a mutable aggregate, a run UUID, and a content hash are not automatically a grain dimension or source version. `NOT-APPLICABLE` is available as a classification but no declared dimension was silently waived here.

A run ID and its evidence hash identify a run/snapshot; neither is automatically each source's version.

## E. Migration-NONE feasibility and bounded alternatives

**As the approved contract stands, no pair is demonstrated implementable end-to-end under Migration-NONE for PD-033 current-state selection.** The eight direct-source pairs and the gated pair require D01 or a pair-specific applicability decision; `commitment_projection`, `inventory_quantity_value`, and `project_cost_sources` additionally have missing/ambiguous dimensions. The four native-reconciliation adapters (`subledger_gl`, `treasury_bank`, `treasury_gl`, `payroll_insurance`) lack an approved deterministic repeat-run order or complete eligibility interpretation; `subledger_gl` and `treasury_gl` additionally lack declared run-grain dimensions. This is an evidence statement, not a claim that all 13 need migrations.
