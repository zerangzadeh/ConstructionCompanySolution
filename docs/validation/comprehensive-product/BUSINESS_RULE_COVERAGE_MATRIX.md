# BONIRA business rule coverage matrix

A rendered page or successful response is one observation. PASS requires the applicable UI, authoritative state, denial and failure-path assertions, including no write for read-only actions. Use an independent pre/post snapshot. Dates, Decimal values, immutable versions, source IDs and audit actor must come from the owning domain. For failed or concurrent operations compare both resulting state and absence of partial writes.

[Editable execution matrix](TEST_EXECUTION_MATRIX.csv) contains per-route test-source references and live fields for observed evidence, status and PO disposition. The table below associates existing evidence with planned checks.
