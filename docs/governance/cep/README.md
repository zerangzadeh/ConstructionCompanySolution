# CEP governance artifacts

- `PROMPTS/` — canonical CEP execution contracts for CEP-001 through CEP-079.
- `reports/` — CEP completion reports.
- `manifests/` — execution and change manifests.
- `evidence/` — evidence manifests and acceptance mappings.
- `supporting/` — CEP-specific support, recovery, reauthorization, decision, and
  finding records.
- `CEP_PROMPT_MANIFEST.yaml` — canonical prompt identities and hashes.

CEP-080 through CEP-086 remain `DEFERRED_POST_V1` without canonical prompt
files. [`CEP_EXECUTION_REGISTRY.yaml`](../../../CEP_EXECUTION_REGISTRY.yaml) is
the live CEP lifecycle and state authority; this directory does not duplicate it.
